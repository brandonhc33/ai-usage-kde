## Product Description

```text
AI Usage is a read-only KDE Plasma 6 panel widget that monitors Codex and Claude usage limits.

It shows the current session/5-hour and weekly limits, reset times, available credits when provided, stale data warnings, and manual refresh actions.

The widget uses the existing local sessions from Codex CLI and Claude Code. It does not send prompts, consume credits, or make AI requests on your behalf. Tokens and cookies are never written to the widget status file.

Requirements:
• KDE Plasma 6
• Node.js 18 or newer
• Codex CLI and/or Claude Code authenticated locally
• Plasma 5 Support QML module

Supported distributions include Arch Linux, CachyOS, Manjaro, Debian 13+, and Ubuntu/Kubuntu releases that ship Plasma 6.

Español:

AI Usage es un widget de panel de solo lectura para KDE Plasma 6 que monitorea los límites de uso de Codex y Claude.

Muestra los límites de la sesión/5 horas y semanales, los reinicios, los créditos disponibles cuando el proveedor los entrega, advertencias de datos antiguos y actualización manual.

El widget utiliza las sesiones locales existentes de Codex CLI y Claude Code. No envía prompts, no consume créditos ni realiza solicitudes de IA en tu nombre. Los tokens y cookies nunca se escriben en el archivo de estado del widget.

Requisitos:
• KDE Plasma 6
• Node.js 18 o posterior
• Codex CLI y/o Claude Code autenticados localmente
• Módulo QML Plasma 5 Support

Compatible con Arch Linux, CachyOS, Manjaro, Debian 13+ y versiones de Ubuntu/Kubuntu que incluyan Plasma 6.
```
